# S.A.M. Reader (Chrome extension)

Lets the « Read the portals » button of S.A.M. (Projects › CAA applications) read TMCAD — and METEOR next — in your own signed-in
Chrome session. Read-only: GET requests to the portal's pages, nothing clicked, saved or sent on the portal. No password is stored
or typed by the extension: if a portal shows its sign-in page, S.A.M. asks you to sign in and click again.

Install (once per computer, for the people allowed to read the portals):
1. Chrome › `chrome://extensions` › turn on « Developer mode ».
2. « Load unpacked » › choose this folder (`extension/sam-reader` of the S.A.M. repository).
3. Reload the S.A.M. tab: the button says « Read the portals ».
